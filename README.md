# Gurme Tema Stüdyosu

Gurme mobil uygulaması için görsel kimlik denemeleri yapılan 3 panelli stüdyo:
şablonlar, renk paletleri, "Gurme" yazım stilleri ve bileşen kombinasyonları (kampanya animasyonları,
mutfak görselleri, alt bar tasarımları). Sağ panel her seçimi canlı olarak değerlendirir.

Tüm içerik ve görseller temsilidir.

## Çalıştırma

```bash
npm install
npm run dev
```

`main` dalına her gönderimde GitHub Actions siteyi GitHub Pages'e yayınlar.
